# Project Eleven

A programming kata to learn TDD with Nextjs.

It is used for training purpose within [Better Engineering Community](https://www.withnik.com/community) founded by Nik Sumeiko.

## Getting Started

```bash
npm install
npm start
```

This starts both the API server (http://localhost:3210) and the React app
(http://localhost:3000) in parallel.

When opening the app in the browser at http://localhost:3000, expect to see an almost blank page. This is a starting point.

#### Useful npm scripts

Review all available npm scripts in [`package.json`](./package.json) (esp. testing scripts).
